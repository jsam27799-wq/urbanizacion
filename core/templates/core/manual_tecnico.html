Manual técnico

Referencia inicial para ejecutar, mantener y desplegar el sistema Piemonte.

Visible solo para Administrador

Protege la configuración de producción

No publiques claves, contraseñas ni datos reales. Antes de desplegar, guarda SECRET_KEY fuera del código, desactiva DEBUG y configura ALLOWED_HOSTS, HTTPS y copias de seguridad.

01

Organización del proyecto

La solución está construida con Django y separa las responsabilidades principales:

  • core/Acceso, perfil, página pública, manuales y recursos compartidos.
  • BD/Modelos, permisos, vistas y pantallas de gestión.
  • Piemonte/Configuración del proyecto y rutas principales.
  • templates/ y static/Interfaz, estilos, scripts e imágenes.
02

Entorno y base de datos

El entorno del proyecto usa Django 6.0.6 y una base SQLite local llamada BD.sqlite3.

Antes de trabajar Activa el entorno virtual del proyecto y conserva una copia de la base de datos antes de realizar cambios importantes.
Abrir Copias de Seguridad →
03

Iniciar el servidor local

Desde PowerShell, en la carpeta del proyecto:

..\.venv\Scripts\Activate.ps1
python manage.py runserver

En esta instalación, el entorno virtual está en la carpeta superior al proyecto. Abre la dirección local indicada por Django; para detenerlo, usa Ctrl + C en la terminal.

04

Cambios en los modelos

Cuando se modifiquen modelos, genera y aplica migraciones:

python manage.py makemigrations
python manage.py migrate

Revisa los archivos de migración antes de aplicarlos en producción y respalda la base de datos.

05

Pruebas

Ejecuta la suite desde la carpeta que contiene manage.py:

python manage.py test

Para validar un módulo específico, indica su etiqueta, por ejemplo python manage.py test core.

06

Lista previa al despliegue

  • Configura secretos y credenciales mediante variables de entorno.
  • Desactiva el modo de depuración y limita los hosts permitidos.
  • Configura HTTPS, archivos estáticos y almacenamiento de medios.
  • Verifica permisos por rol, migraciones y restauración de respaldos.
