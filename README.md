# Urbanizacion Piemonte

Aplicacion web de gestion de la Urbanizacion Piemonte desarrollada con Django.

## Instalacion

1. Crea y activa un entorno virtual de Python.
2. Instala las dependencias:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Configura las variables locales necesarias en `.env`.
4. Inicia el servidor de desarrollo:

   ```powershell
   python manage.py runserver
   ```

Los archivos de configuracion privada, bases de datos locales, respaldos, exportaciones y archivos subidos no forman parte del repositorio.
